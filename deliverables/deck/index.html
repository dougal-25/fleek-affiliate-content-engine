Part 2 — Outreach

The engine drafts. A human sends. Always.

Human qualifies a creator → the draft job fires. It reads their real recent posts, picks one or two facts from a value palette that fit their niche, and writes a 3-touch French sequence. Every figure is wiki-sourced; anything it can't source it flags human_check rather than invent.

First name, never the handle, never invented. "Alicia 🌙" → Salut Alicia. "CODE DES GRANDS ✦ Friperies" → no name, opens on their content. A shop name is not a name.

It cannot send. There is no send code path in the repo — no smtplib, no DM client. The gate holds because the capability is absent, not because a flag is off.

Honest, not impressive — and that's the point. 162 recommended, 7 qualified, nothing past the gate, because outreach never auto-sends. The funnel is a view of the same database, not a second system.

The 10-stage economics — Prospect → Qualified → … → Repeat poster — is on the dashboard's funnel page with an illustrative projection modelled, clearly labelled. The cliff is Signed → first post: that gap is the whole job.

Why the gate is manual, on purpose

Passing the bar sets Recommended = true. Stage stays Prospect until a person runs qualify.py @handle — which refuses to guess an ambiguous handle and flags any approval the engine didn't recommend as a human override.

Qualification is what releases the draft. "A signed partner is someone we want to work with" — so approval is deliberate, never automatic.

Part 4 — Activation. "The whole game."

Nobody hand-writes 475 briefs. So the engine writes them.

For each creator: profile them from their own post history, study what has already converted for them, then generate a brief in their format, their hook, their vocabulary.

Feedback closes the loop — last month's post performance becomes next month's brief. That loop, not the generator, is the asset.

How to get partners posting more without paying more per post: pay them in sourcing advantage, not cash. French resellers already pay for private Discord coaching. Fleek is the only party that can offer commission and wholesale margin in one relationship.

Part 5 — Budget, CAC, 30/60/90

Models write briefs. Code moves money — and CAC is a constraint, not the selector.

The trap I designed around: CAC is reach-weighted, and the brief says trust beats reach. Run the numbers on Fleek's own named partners and CAC ranks them badly. So fit selects the shortlist; CAC is the budget constraint. Predicted CAC ships as a band — £ / ££ / £££ with a confidence — never a false-precision point.

The real model needs three numbers only Fleek has: referral funnel rate, first-order AOV by tier, LTV by segment. Until then it's honest scaffolding, not a shipped figure.

Money splits recruitment vs re-activation, reallocates monthly toward best-CAC segments — deterministic code, never a model.

simulated roster The allocator runs today against a 1,000-creator simulation — proving the mechanism, not reporting Fleek's numbers.
